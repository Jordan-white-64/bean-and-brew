# Bean and Brew

A multi-page website for Bean and Brew, a fictional coffee shop. It has a home page, an about page, an events ("What's on") page, a menu and a table booking form with a confirmation page.

## Pages
- `index.html`: home
- `about.html`: about us
- `whatson.html`: events
- `menu.html`: menu
- `book.html`: table booking (validated in `order.js`, details saved to `localStorage`)
- `confirmation.html`: booking confirmation

## Built with
HTML, CSS and plain JavaScript. No build step: open `index.html` in a browser.
